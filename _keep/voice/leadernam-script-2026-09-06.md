## 대본에서 뽑은 특징 (실측)

| 특징 | 대본의 예 |
|---|---|
| 독자의 상황을 **질문**으로 열고, 독자의 속말을 따옴표로 2~4줄 | "그런데 솔직히 이런 생각 든 적 없으신가요?" → "글은 계속 쓰는데 왜 방문자는 안 늘지?" |
| 한 줄에 한 생각. 나열은 짧은 구절을 세로로 | "키워드를 찾아야 하고, / 글의 역할을 나눠야 하고, / 이미지를 준비해야 하고" |
| 핵심 앞에 **길잡이 문장** | "그런데 여기서 먼저 짚고 넘어갈 게 있습니다." / "여기서 중요한 게 있습니다." |
| 반론을 먼저 인정하고 뒤집기 | "이런 말씀을 많이 하십니다. 이 걱정은 충분히 이해합니다. 그런데 …" |
| 어려운 말 뒤에 **"쉽게 말하면"** | "쉽게 말하면 LEWORD는 키워드, … Orbit는 글 연결과 외부 유입입니다." |
| 솔직한 단서 | "다만 주의하실 점이 있습니다." / "보장하는 도구는 아닙니다." |
| 기준은 번호로, 번호마다 **왜** | "첫 번째, 검색 의도가 분명한가. … 납득이 되어야 합니다." |
| 독자에게 되묻는 마무리 | "어떠신가요?" / "간단하죠?" / "힌트가 되시죠?" |
| 어미: 설명은 합니다체, 공감·마무리는 "~죠 / ~거든요 / ~잖아요" | "에너지가 다 빠지죠." / "요즘은 스레드 많이들 하시잖아요?" |
| 편한 영상(세팅)에서는 "~구요 / ~더라구요 / !! / ?? / ~" | "간단하죠?? 블로그스팟만 좀 어렵구요" |

**주의**: 사장님의 자연 말투는 순수 해요체가 아니라 **합니다체 바탕 + 공감 어미(죠·거든요·잖아요) + 물음표·느낌표**다.
앱의 "친근한" 설정은 v3.8.670 부터 해요체로 통일한다. 어느 쪽으로 갈지는 사장님 결정(7-20 보고에 물음).

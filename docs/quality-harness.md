## 4. 못 재는 것 — 사람이 읽어야 한다

오늘 10편을 실제로 읽고 확인한 것. **점수 94인 글에서도 전부 보였다.**

| 무엇 | 왜 못 재나 | 돈과의 관계 |
|---|---|---|
| 제목 ↔ 본문 **범위** 일치 | 수치 약속은 title-claim-check.ts 가 봄 ("9월 30일" 이 본문에 있나). 주제 범위("상품별 비교" 인데 한 상품만)는 못 봄 | 제목 보고 들어와 다른 글이면 그대로 나감 |

| 사실이 **맞는가** | 밀도만 잼, 진위는 안 봄 | 돈 걸린 글에서 틀리면 신뢰 끝 |
| 결론 박스가 답을 다 줘서 스크롤 유인이 없나 | 구조 검사 없음 | **광고 수익과 직결** — 답 얻고 나가면 광고를 안 본다 |
| 지역 사례를 전국처럼 쓰나 | 지역명 빈도만 셀 수 있음 | 다른 지역 독자가 기한을 놓친다 |

## 7-22. v3.8.675 — 리터치 없이: 사람이 봐야 했던 세 곳을 코드가 잡는다

사장님: "리터치를 수동으로 또 하면 자동화를 쓰는 이유가 없어." 오늘 라이브 2편에서 발행 전에 사람이 봐야 했던 곳:
- **CTA 오배송(주택연금 → 국토교통부)**: 로그를 되짚으니 행동 화면 판정은 hf.go.kr 페이지를 8점으로 골랐다. 그런데 `isContextuallySafeCtaUrl` 이
  정부 도메인을 "키워드에 신청·등록·민원이 없다" 는 이유로 "주제-링크 불일치" 차단했고, 카탈로그 폴백이 "주택" 낱말로 국토교통부 홈을 골랐다.
  → 정부·공공 도메인만 걸리고 다른 분류가 없으면 통과. 카탈로그가 고른 기관이 글이 지목한 기관과 다르면 **붙이지 않는다**(엉뚱한 버튼 < 없는 버튼).
- **답 상자의 회피 문장** "…절차도 함께 확인해요" → 회피 문장만 뺀다(남는 문장이 둘 이상일 때). 전부 회피면 상자를 안 만든다.
- **지목 기관 쓰레기** "계속됐는지처" → 용언 꼬리가 든 이름은 기관이 아니다.
남은 리터치 사유: 근거에 없는 사실(리포트·검색이 못 준 것)은 코드가 못 만든다 — 이건 리포트 품질의 몫이다.

## 8. 아직 못 재는 것

- 사실이 **맞는가** — 팩트체크 체인(퍼플렉시티·네이버 뉴스·기관 문서)이 따로 본다
- FAQ 가 답을 **피하는가** — "먼저 확인해 봐야 해요" 는 낱말이 맞아도 답이 아니다
- 지역 사례 → 전국 확장 — 사장님이 의도라 하셨으니 안 잰다

## 원칙

- 검사기는 지우지 않는다. 알려만 준다. 지우는 건 auto-repair 가 **기계로**.
- 정상 글이 걸리면 검사기를 의심한다 — 오늘 다섯 번 그랬다.
- 점수는 감점식 — 무엇 때문에 깎였는지 되짚을 수 있어야 한다.
- 점수가 높다 ≠ 읽기 좋다. **10편 뽑았으면 읽는다.**

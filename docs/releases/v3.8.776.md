# Orbit 3.8.776

- 티스토리 크롬 창이 Orbit 이 떠 있는 화면에 열립니다. 전에는 늘 주 모니터의 정해진 자리에 열려서, 모니터를 두 대 쓰거나 꺼진 화면이 주 모니터로 잡혀 있으면 창이 보이지 않을 수 있었습니다.
- [로그인 창 열기]를 누르면 크롬이 실제로 떠 있는지 확인한 뒤에 알려 줍니다. 단추 옆에 브라우저 버전과 창 위치가 함께 나오고, 크롬이 떴다가 바로 꺼졌으면 "열렸다가 바로 닫혔습니다"로 알려 줍니다.
- 창이 안 보일 때는 Alt+Tab 으로 찾을 수 있다는 안내를 단추 옆에 넣었습니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 581묶음 8,514개 통과. 실제 크롬으로 새로 열기·숨긴 뒤 다시 열기·크롬이 꺼진 경우를 확인했고, 화면 위치를 바꿔 알려 주면 창이 그 자리에 뜨는 것도 확인했습니다. 모니터가 두 대인 PC 에서는 시험하지 못했습니다. 창이 보이지 않는다는 신고의 원인이 모니터 배치인지는 아직 확인되지 않았습니다.

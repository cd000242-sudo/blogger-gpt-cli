# Orbit 3.8.774

- 클로드 코드로 만든 글은 발행 전에 claude-seo 스킬 기준(답 먼저, 인용되기 쉬운 문장, 읽기 쉬움)으로 한 번 점검하고, 분명히 부족한 곳만 고칩니다.
- 글 전체를 다시 쓰지 않고 고칠 구절만 바꿉니다. 숫자, 고유명사, 제목, 소제목 제목, 링크는 바꾸지 않습니다.

# Orbit 3.8.768

- 연속발행 중 첫 글이 오래 걸리면 대기열이 멈춘 것처럼 보이던 문제를 고쳤습니다. 젠스파크 심층 분석 진행 상황이 대기열 화면에 보입니다.
- 연속발행을 중지하면 젠스파크 대기와 Claude Code 실행이 실제로 멈춥니다. 전에는 중지 뒤에도 글이 발행될 수 있었습니다.
- 중지 뒤 다시 시작하면 첫 글이 바로 실패하던 문제를 고쳤습니다(앞 작업이 끝날 때까지 기다린 뒤 시작).
- 완료 0 · 실패 0 인데 "일부 실패"로 뜨던 오판을 고치고, 중지 요약에 언제 무엇이 멈췄는지 적습니다.
- AI 연결의 계정 선택에 실제 계정 이메일이 보이고, 같은 계정은 하나로 묶어 보여 줍니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 547묶음 7,883개 통과. 실제 앱에서의 긴 연속발행과 계정 목록은 시험 코드로만 확인했습니다.

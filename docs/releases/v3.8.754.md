# Orbit 3.8.754

- 편집기 도구를 오른쪽 접이식 패널로 정리했습니다. 이미지·서식·글 수정·넣기·엔진/발행 도구를 각각 펼치거나 접을 수 있습니다.
- 썸네일 생성에 텍스트 포함 선택을 추가했습니다. 텍스트 생성 미지원 엔진은 추가 AI 호출 없이 제목을 합성합니다.
- 소제목 이미지 버튼을 이미지 모두 생성으로 통합했습니다. 전체·홀수·짝수·썸네일만 범위를 선택할 수 있으며, 전체·홀수·짝수는 썸네일을 포함합니다.
- 외부 HTML의 소제목을 읽어 이미지를 만들고 글과 스타일을 유지합니다. 프로필 사진·아이콘은 자동 교체에서 제외합니다.
- 이미지 생성 중지와 실패 후 이어 생성을 지원합니다. 완료된 이미지는 보존하고, 합성·업로드만 실패한 이미지는 최대 1시간 보관해 생성 API 재호출 없이 후처리할 수 있습니다.
- 일부 브라우저·보조 프로세스 실행 시 Windows 콘솔 창이 나타나던 숨김 옵션 누락을 수정했습니다.
- 이미지 엔진 가용성 검사에서 전달받은 Gemini 설정을 무시해 다른 엔진으로 바뀔 수 있던 문제를 수정했습니다.

실제 유료 생성 API 호출 없이 모의 응답 기반 회귀 테스트와 Chromium 편집기 검증을 수행했습니다.

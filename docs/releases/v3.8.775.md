# Orbit 3.8.775

- 티스토리 글이 제목과 썸네일만 있는 채로 발행되던 문제를 고쳤습니다. 썸네일을 올린 글에서 티스토리 편집기가 본문을 넣기 전 상태로 되돌리는 것이 원인이었습니다. 이제 본문이 실제로 들어갔는지 확인한 뒤에만 발행하고, 끝내 들어가지 않으면 발행하지 않고 알려 줍니다.
- 티스토리 [로그인 창 열기]를 눌러도 크롬 창이 보이지 않던 문제를 고쳤습니다. 창이 화면 밖에 떠 있었습니다. 이미 로그인된 상태에서 열어도 창이 바로 사라지지 않습니다.
- 글 작성 뒤 바로 발행할 때도 발행 단계의 진행 내용이 로그에 나옵니다.
- 워드프레스 다중 계정 발행에서 글이 전부 기본 설정 계정 하나로 올라가던 문제를 고쳤습니다. 이제 계정마다 자기 사이트와 아이디로 발행합니다. 계정 칸의 주소·아이디·앱 비밀번호가 틀리면 그 계정은 실패로 표시됩니다(예전에는 기본 계정으로 올라가 성공처럼 보였습니다).

검증: 타입 검사 오류 0, 전체 회귀 시험 580묶음 8,502개 통과. 티스토리는 실제 편집기에서 임시저장한 글을 다시 불러와 본문이 그대로 저장된 것을 확인했고(썸네일 있는 글·없는 글), 비공개로 한 편 발행해 발행된 글에 본문이 있는 것도 확인했습니다. 워드프레스 다중 계정은 실제 발행 코드를 시험용 서버에 연결해 확인했고, 실제 사이트 2개로는 발행해 보지 않았습니다. 이미 발행한 티스토리 글을 고치는 기능과 Flow 이미지는 이번에 포함되지 않았습니다. 설치본에서의 실제 발행은 확인하지 않았습니다.

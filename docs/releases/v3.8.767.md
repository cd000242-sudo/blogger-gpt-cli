# Orbit 3.8.767

- 환경 설정의 "API 키" 탭을 "AI 연결"로 바꿨습니다. 엔진마다 상태 한 줄과 [연결하기] 버튼 하나만 보입니다. 버튼 하나로 준비 확인, 설치, 로그인, 실제 답 확인을 순서대로 하고 끝난 단계는 건너뜁니다.
- Claude Code·Codex 확인이 늦어도 로그아웃으로 보지 않습니다. "확인 지연"으로 따로 표시하고, 6시간 안에 확인된 로그인은 다시 씁니다.
- 묻지 않고 설치·업그레이드하던 동작을 없앴습니다. 앱 안 확인창에서 [설치]를 눌러야 진행하고, 이미 있는 Claude Code 는 덮어쓰지 않습니다.
- 엔진·상단 배지가 몰래 다른 쪽으로 바뀌던 동작을 없앴습니다.
- 앱을 켠 직후와 상태 확인 때 멈추던 현상을 줄였습니다. 시작 12초간 그래픽 부하를 만들던 제목 반짝임 효과를 없애고, 백업과 프로그램 위치 찾기를 뒤에서 돌립니다.
- 연속발행에서 에이전트 항목이 already_running 으로 끝나던 길을 닫았습니다. 연속발행·다중계정에 이미지 글자 체크를 추가했습니다.
- 젠스파크 심층 분석: 로그인이 풀리면 10분을 기다리지 않고 바로 멈춥니다. 단계별 시간을 기록합니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 543묶음 7,796개 통과. 실제 앱에서의 [연결하기] 전 과정과 Codex 업그레이드는 시험 코드로만 확인했습니다.

# Orbit 3.8.772

- 워드프레스 글에서 썸네일이 제목 위(대표 이미지)와 본문 맨 위에 두 번 나오던 문제를 고쳤습니다. 편집기에서 이미지를 만든 뒤 [수정발행]한 글에서 생기던 문제입니다. 새로 발행하는 글도 같은 방식으로 한 번만 나오게 했습니다.
- 이미 두 번 나오는 글은 이 버전에서 편집기로 열어 [수정발행]을 한 번 하면 본문 쪽 썸네일이 빠집니다.
- 블로그스팟·티스토리 글은 달라지는 것이 없습니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 569묶음 8,286개 통과. 실제 워드프레스 발행 화면은 시험 코드로만 확인했습니다.

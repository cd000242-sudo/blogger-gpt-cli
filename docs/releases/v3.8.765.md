# Orbit 3.8.765

- 젠스파크 이미지 엔진을 선택하면 바로 아래에 로그인 버튼, 상태 확인 버튼, 계정 연결 상태가 표시됩니다. 이미지 설정, 편집기, 대기열 등 이미지 엔진을 고르는 화면에 공통 적용했습니다.
- 리서치와 이미지 생성은 같은 젠스파크 계정을 사용하며, 로그인 상태와 확인 중 표시를 함께 갱신합니다. 여러 버튼을 눌러도 로그인 창이나 상태 확인 요청을 중복 실행하지 않습니다.
- 이미지를 생성하기 전에 로그인을 확인합니다. 로그인이 필요하면 전송을 멈추고 로그인 버튼 위치를 안내하며, 생성 중 세션이 만료돼도 시간 초과까지 기다리지 않고 안내합니다.
- 이미지 URL 없이 실패 상태만 반환된 작업도 즉시 실패로 처리합니다.

검증: 젠스파크·이미지 엔진 관련 108개 회귀 테스트와 앱 빌드를 통과했습니다. 로컬 브라우저에서 로그인 버튼·자동 상태 확인·편집기 동적 표시·상태 동기화를 확인했습니다. 인증과 이미지 생성 응답은 모의 데이터로 검증했으며 실제 계정 이미지 생성 성공을 확인한 것은 아닙니다.

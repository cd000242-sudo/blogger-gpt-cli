# Orbit 3.8.773

- 드롭샷(리더스 나노바나나) 이미지 생성이 "결과 이미지 미발견"으로 실패하던 문제를 고쳤습니다. 드롭샷이 결과 이미지 주소 형식을 바꾼 것이 원인이었습니다. 결과를 기다리는 시간도 210초에서 360초로 늘렸습니다.
- 드롭샷 로그인을 끝냈는데도 "6분 내 로그인 미완료"로 닫히던 문제를 고쳤습니다. 이제 로그인이 되면 바로 알아채고 앱이 생성 화면으로 넘어갑니다.
- 드롭샷 로그인 창이 열려 있을 때 로그인 단추를 또 누르면 빈 탭이 여러 개 뜨고 긴 오류 창이 나오던 문제를 고쳤습니다. 이미 열린 창을 앞으로 가져오고, 오류는 짧은 안내로 보여 줍니다.
- 워드프레스 태그가 제목을 쪼갠 낱말('방법과', '예약하는' 등)로 들어가던 문제를 고쳤습니다. 태그가 모자라면 AI 가 글에 맞는 태그를 만들어 채웁니다.
- 이전 버전에서 생긴 'object Object' 태그는 워드프레스 관리자 > 글 > 태그에서 그 태그 하나를 삭제하면 모든 글에서 빠집니다(글은 지워지지 않습니다).

검증: 타입 검사 오류 0, 전체 회귀 시험 573묶음 8,381개 통과. 드롭샷은 수정 후 실제 생성 3회 성공(36초·162초·179초). 로그인 창이 열린 채 단추를 다시 누르는 화면과 실제 워드프레스 발행의 AI 태그는 시험 코드로만 확인했습니다.

# Orbit 3.8.756

- 환경설정에 넣은 네이버 검색 API(API HUB) 키가 실제 검색에 쓰이지 않던 문제를 고쳤습니다. 키가 화면에만 저장되어 글 근거를 하나도 찾지 못하고 "확인하는 방법" 같은 내용 없는 글이 나올 수 있었습니다. 이미 키를 넣어 두신 경우 업데이트 후 앱을 켜면 자동으로 반영됩니다.
- 네이버 검색 키와 "키워드 분석" 카드의 Customer ID 를 함께 넣으면 검색 키가 덮이던 문제를 고쳤습니다.
- Dropshot 사이트가 무제한 모드 스위치와 생성 개수 버튼 모양을 바꿔, 무제한 구독자도 이미지 생성이 실패하던 문제를 고쳤습니다(예전·새 모양 모두 인식).
- 전용 브라우저가 없는 PC 에서 쇼핑모드 상품 정보 수집, URL 이미지 자동 수집, URL 모드 상품 수집이 바로 실패하던 문제를 고쳤습니다. 이제 PC 에 있는 Edge·Chrome 으로 실행합니다.
- 네이버가 오류 페이지를 돌려줄 때 그 제목을 상품명으로 받아 글을 쓰던 문제를 막았습니다.

실제 사이트(드롭샷 보드)와 실제 앱에서 검증했고, 새 PC 조건(전용 브라우저 없음)에서 수정 전 실패·수정 후 정상 실행을 확인했습니다.

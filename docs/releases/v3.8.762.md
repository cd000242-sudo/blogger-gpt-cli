# Orbit 3.8.762

- Claude 모델 목록을 Haiku 5.5 · Sonnet 5.5 · Opus 5.5로 업데이트했습니다. Fable은 선택 목록과 호출 후보에서 제거하고, 기존 Fable 선택값은 Sonnet 5.5로 이전합니다.
- 조직·팀 API 키에 필요한 작업공간 ID를 설정할 수 있습니다. **설정 → Claude API 키 → Claude 작업공간 ID**에 Console의 `wrkspc_...` ID를 입력하세요. 작업공간 전용 키는 비워 둘 수 있습니다.
- **연결 확인** 버튼으로 글 생성 비용 없이 키·작업공간 연결을 확인할 수 있습니다. 이 검사는 생성 한도나 블로그 발행 권한까지 확인하지는 않습니다.
- 작업공간 설정 오류는 정확한 설정 안내와 함께 즉시 중단합니다. 같은 오류로 불필요한 재시도·모델 변경을 하지 않습니다.
- 글 생성·이미지 분석·외부 트래픽 문안 경로에 작업공간 헤더를 적용하고 Claude 5.5 요청 옵션을 정리했습니다.
- 설정 저장 실패가 성공으로 표시되거나 이전 Claude 키·작업공간 값이 남는 문제를 수정했습니다.

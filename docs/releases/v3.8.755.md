# Orbit 3.8.755

- Codex 설치를 원클릭으로 바꿨습니다. Node.js·npm·관리자 권한 없이 OpenAI 공식 Codex 실행 파일을 직접 내려받고, 공식 무결성 값(sha256)과 대조한 뒤 설치합니다.
- 설치 창에 내려받기 진행률(%)을 표시합니다. 설치가 끝나면 로그인 창이 자동으로 열리고, 설치 전에 로그인 버튼을 눌러도 설치부터 진행합니다.
- 직접 내려받기가 막힌 환경에서는 npm → winget 순서로 다시 시도하고, 오류 문구가 깨진 글자로 보이던 문제를 고쳤습니다.
- Gemini CLI 설치하기 버튼이 Codex를 설치하던 문제를 고쳤습니다. Gemini CLI도 공식 번들과 공식 Node.js를 함께 받아 원클릭으로 설치합니다.
- 설치된 에이전트 실행 확인 시간을 늘려, 느린 PC에서 정상 설치된 도구를 "실행 안 됨"으로 판정하던 문제를 고쳤습니다.
- Dropshot 로그인 판정을 바로잡았습니다. 로그아웃 상태에서도 "로그인 완료"로 표시되던 문제를 고치고, 이미지 생성용 배경 브라우저가 로그인을 이어받는지까지 확인합니다.

실제 GitHub·nodejs.org 공식 파일로 설치를 검증했고, 새 PC 조건(Node.js 없음)에서 실제 앱 화면 버튼으로 설치→로그인 창 열기까지 확인했습니다.

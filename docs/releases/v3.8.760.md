# Orbit 3.8.760

- **젠스파크 정밀 리서치를 추가했습니다.** 설정 → 콘텐츠 탭의 "🔎 젠스파크 정밀 리서치"를 켜면, 글을 쓰기 전에 젠스파크(Genspark) 딥 리서치가 공식기관·뉴스 페이지를 수십 곳 읽고, 그 원문을 근거로 글을 씁니다.
  - 본인 젠스파크 계정이 필요합니다. 같은 칸의 [젠스파크 로그인]을 눌러 열린 창에서 한 번 로그인하면, 창은 자동으로 닫힙니다.
  - 켜면 글 한 편에 2~6분이 더 걸리고, 젠스파크 사용량(무료 할당량, 다 쓰면 크레딧)을 씁니다.
  - 젠스파크가 안 되거나 너무 오래 걸리면 지금처럼 네이버 검색으로 계속 진행합니다. 발행은 멈추지 않습니다.
  - 단일·대기열·예약 발행과 에이전트(Codex) 모드 모두에 적용됩니다. 기본값은 꺼짐입니다.

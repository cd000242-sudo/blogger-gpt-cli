# Orbit 3.8.770

- 이미지 엔진을 젠스파크로 고르면 "연동 방식을 확인하지 못했습니다"로 발행이 멈추던 문제를 고쳤습니다.
- 드롭샷 로그인이 풀렸을 때 "다시 로그인해 주세요" 안내가 나옵니다. 전에는 이유 없이 실패로만 보였습니다.
- 거미줄 종합글 생성이 실패하면 임시 틀 글을 발행하지 않고, 어느 단계에서 왜 멈췄는지 알려 줍니다. 에이전트 모드에서는 Gemini 키 없이도 종합글을 만듭니다.
- 종합글이 워드프레스·블로그스팟에서 일반 글과 같은 폭으로 나옵니다. 모바일에서 관련 글 카드가 한 줄씩 보이고, 이모지가 따로 줄바꿈되지 않으며, 단추 글자가 커졌습니다.
- 편집기의 수정발행이 요약·태그·검색 제목·설명도 함께 반영합니다.
- 굵은 글씨가 "6일까지" 같은 낱말 중간에서 끊기던 문제를 고쳤습니다.
- 거미줄 탭에서 고른 이미지 엔진이 저장됩니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 567묶음 8,238개 중 8,237개 통과. 남은 1개(백업 복사 속도 시험)는 PC가 바쁠 때 시간 초과가 났고, 한가할 때 단독 실행은 통과했습니다. 종합글은 실제 Claude Code 생성 2회와 실제 워드프레스 글로 확인했습니다. 블로그스팟·티스토리 실발행과 젠스파크·드롭샷 실제 생성은 시험 코드로만 확인했습니다.

# Orbit 3.8.758

- 윈도우에서 Codex 에이전트로 글을 쓸 때 Codex 가 작업 지시서를 읽지 못하고 결과 파일도 만들지 못하던 문제를 고쳤습니다. 윈도우용 Codex 의 보호 모드가 읽기 전용으로 떨어지던 것이 원인이었고, 이제 Codex 가 스스로 검토하는 방식으로 실행합니다.
- Codex 가 쓴 글을 가져올 때 본문에 `\n`, `\"` 같은 기호나 시작 표시가 섞이던 문제를 고쳤습니다.
- 블로그스팟 글의 CTA 버튼 끝에 화살표 대신 `&#8594;` 글자가 보이던 문제를 고쳤습니다. 같은 이유로 일부 글꼴이 불려오지 않던 것도 함께 고쳤습니다.
- 글 주제와 상관없는 문서(PDF)가 CTA 버튼으로 연결되던 경우를 막았습니다. 예: 고속도로 통행료 글에 국어 자료 PDF.

구독 로그인 상태의 Codex(GPT-6 Astra)로 지시서 읽기와 파일 쓰기가 되는 것을 확인했습니다.

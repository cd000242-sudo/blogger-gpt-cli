- 앱을 다시 켜면 발행 대상이 블로그스팟으로 돌아가던 문제를 고쳤습니다. 고른 발행 대상이 유지됩니다.

- 이미지가 0장인 글도 [이미지 다시 생성]으로 썸네일과 소제목 이미지를 새로 넣을 수 있습니다.

# Orbit 3.8.764

- URL로 생성한 글을 Agent 모드에서 발행할 때, URL을 입력했어도 “먼저 키워드나 제목을 입력해주세요”로 막히던 오류를 수정했습니다. Agent 작업실에서도 URL만으로 시작할 수 있습니다.
- URL 글은 원문의 주제와 제목을 사용하도록 지시하고, 숨겨진 키워드 입력값과 대기열의 URL 표시용 이름이 주제로 섞이지 않도록 수정했습니다.
- 작업실을 연 상태에서 URL을 바꾸면 이전 URL의 작업지시서를 재사용하지 않습니다. 같은 URL의 지시서를 직접 편집한 내용은 유지합니다.

검증: 관련 29개 테스트 묶음의 384개 테스트와 앱 빌드를 통과했습니다. 실제 렌더러 함수를 실행해 URL 발행 요청, 작업실 실행, 생성된 제목·HTML 반환, 잘못된 URL 차단, 키워드 모드를 확인했습니다. 외부 Agent 생성과 공개 블로그 발행은 모의 응답으로 대체했습니다.

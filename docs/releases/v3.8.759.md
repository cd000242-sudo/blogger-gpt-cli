# Orbit 3.8.759

- 리더스 나노바나나 무제한(Dropshot)으로 이미지를 만들 때, 내가 요청한 그림이 아니라 Dropshot 화면에 떠 있던 다른 작업의 이미지가 글에 들어갈 수 있던 문제를 고쳤습니다. 이제 내 생성 결과만 받습니다.
- 같은 엔진에서 이미지 한 장에 7분 넘게 걸리던 문제를 고쳤습니다. 결과 이미지가 나와도 받아 오지 못해 기다리던 것이 원인이었습니다.
- 에이전트 모드에서 "이미지 배치 모드"를 홀수·짝수로 골라도 모든 소제목에 이미지를 만들던 문제를 고쳤습니다. 이제 화면에서 고른 배치를 따릅니다.

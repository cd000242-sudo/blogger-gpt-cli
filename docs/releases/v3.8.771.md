# Orbit 3.8.771

- 젠스파크에 로그인돼 있는데도 이미지 생성이 전부 실패하던 문제를 고쳤습니다. 젠스파크 화면에 새로 뜨는 안내 창이 전송 단추를 가리고 있었고, 화면 없이 요청하면 젠스파크가 "서버가 과부하 상태입니다"로 거절하고 있었습니다.
- 젠스파크가 요청을 거절하면 3분을 기다리지 않고, 젠스파크가 한 말 그대로 바로 알려 줍니다.
- 젠스파크 이미지를 만드는 동안 화면 밖에 브라우저 창이 하나 열렸다 닫힙니다(작업표시줄에 잠깐 보일 수 있습니다).

알아 두실 점: 젠스파크 계정의 요금제에 따라 그림 가운데에 "Genspark" 워터마크가 들어갈 수 있습니다. 이것은 젠스파크가 정하는 것이며, 앱은 받은 그림을 그대로 씁니다.

검증: 타입 검사 오류 0, 전체 회귀 시험 568묶음 8,249개 통과. 실제 젠스파크 계정으로 앱 안에서 이미지 1장 생성 성공(67초). 고객 PC와 젠스파크 리서치 기능은 따로 확인하지 못했습니다.

# 02. 노동·퇴직

> **"일하다 그만둘 때 받을 돈."**
> 실업급여·퇴직금·연차수당·산재·부당해고. 검색하는 순간 이미 절박하다.

## 0. 판정

| 항목 | 값 |
|---|---|
| 광고 단가 | **상** (금융·법률 인접. 보험·대출 광고가 붙는다) |
| 검색량 | **매우 큼 · 연중 고른 편** — 퇴사는 계절을 안 탄다 |
| 진입 난이도 | **하** — 8개 중 가장 쉽다. 고용24 문서가 극도로 불친절하다 |
| 매각 배수 | 30~35배 |
| 추천 | ⭐⭐⭐ **가장 먼저 만들기 좋다.** 난이도 대비 수익이 제일 낫다 |

**이 주제의 핵심 성질:** 검색자가 **화가 나 있거나 불안하다.** "회사가 퇴직금을 안 준다",
"실업급여 얼마 나오나". 감정이 실린 검색은 끝까지 읽고, 저장하고, 공유한다 —
디스커버가 좋아하는 신호가 자연스럽게 나온다.

## 1. 벤치마크

### 한국

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **고용24 / 근로복지공단** (공식) | **베낄 대상이 아니라 반면교사.** 절차는 다 있는데 "그래서 나는 얼마 받나"에 답을 안 한다. 우리가 채울 빈자리가 정확히 거기다 |
| **찾기쉬운 생활법령정보** (easylaw.go.kr) | 법 조문을 생활어로 옮기는 방식이 훌륭하다. **문답 구조**를 그대로 가져올 만하다 |
| 실업급여 계산기형 블로그들 | 국내 상위는 대부분 개인 블로그다 — **즉 뚫린다.** 이들이 안 하는 것: 근거 조문·기준일 표기, 사례별 분기 |

### 영어권

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **moneyunder30.com** | 커리어 초반의 돈 문제를 다룬다. **독자를 한 명으로 특정**하는 방식(20대 후반 직장인)이 강력하다 |
| **thebalancemoney.com** (Careers 섹션) | 실업수당·퇴직 관련 미국 콘텐츠의 표준 구조. **상태별 분기**(주별 규정)를 우리는 고용형태별 분기로 옮긴다 |
| **physicianonfire.com** | 특정 직군에 특화해 성공한 사례. 우리도 **직군별 시리즈**(간호사·건설·프리랜서 실업급여)로 쪼갤 수 있다 |

### 베끼지 않을 것

- 노무사 사무실 사이트의 **상담 유도형 구조**. 광고 수익 모델과 충돌한다.
- 계산기만 있고 설명이 없는 도구형 사이트. 애드센스는 체류시간을 본다.

## 2. 사이트 설계

**사이트명 후보:** 퇴사의기준 / 받을돈 / WORKOUT(work+out) / 실업급여닷
**태그라인:** "그만둘 때 받을 돈, 다 받는 기준"

**카테고리 6개**

| 카테고리 | 슬러그 | 다루는 것 |
|---|---|---|
| 실업급여 | `unemployment` | 수급 조건, 금액, 신청 절차, 부정수급 |
| 퇴직금·퇴직연금 | `severance` | 계산, 중간정산, DC/DB, IRP |
| 임금·수당 | `wage` | 연차수당, 주휴수당, 야간·휴일 |
| 산재·보상 | `injury` | 산재 신청, 요양급여, 장해등급 |
| 해고·분쟁 | `dispute` | 부당해고, 권고사직, 노동위 구제 |
| 4대보험 | `insurance` | 자격 상실·취득, 임의계속 |

**URL:** `/{category}/{postname}/`
**면책:** "개별 사건은 노무사·변호사 상담이 필요합니다."

5. 퇴직금 계산 방법

7. 연차수당 계산법

9. 실업급여 부정수급 기준

**3군 — 산재·분쟁 (21~30)**

## 4. 수익 모델

1. **애드센스** — 보험·대출·법률 광고가 붙는다. 일반 생활정보보다 3~5배.
2. **제휴** — 노무 상담 플랫폼, 실업급여 관련 금융상품. 신중히.
3. **부수 트래픽** — 실업급여 계산기를 자체 제작해 붙이면 체류시간·재방문이 오른다.

## 5. 이 주제의 함정

- **금액이 매년 바뀐다.** 최저임금 연동(실업급여 상·하한액)이라 1월마다 전수 갱신이 필요하다.
- **법률 자문으로 읽히면 안 된다.** "이 경우 승소합니다" 같은 단정은 금지. 면책과 근거 조문을 함께 둔다.
- **개인 블로그가 상위를 먹고 있다** = 뚫리지만, 반대로 **우리도 개인 블로그로 보이면 안 된다.** 저자·소개·연락처로 격을 만든다.
- 부정수급을 **우회 방법으로 읽히게 쓰면 안 된다.** 정책 위반이자 법적 위험이다.

## 6. 6개월 목표와 매각 값

- 검색량이 크고 경쟁이 약해 8개 중 **가장 빨리 트래픽이 붙는다.** 6개월 월 3만~8만 PV 가능
- 단가는 세금·대출보다 낮아 월 **30만~120만원** 수준
- 매각 시: 월 80만원이면 대략 **2,000만~3,200만원**

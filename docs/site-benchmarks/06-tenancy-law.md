# 06. 임대차·생활법률

> **"싸우기 전에 알아야 할 기준."**
> 보증금 반환·계약갱신·소액소송·내용증명·이웃 분쟁. 분쟁 순간에 검색한다.

## 0. 판정

| 항목 | 값 |
|---|---|
| 광고 단가 | **상** — 법률 계열(영어권 RPM $80+). 국내도 법률·부동산 광고가 붙는다 |
| 검색량 | 중상 · 연중 고름 (이사철 3·9월 급증) |
| 진입 난이도 | **중** — 법무법인·로톡이 상위를 잡지만 **상담 유도형이라 끝까지 답하지 않는다** |
| 매각 배수 | 30~40배 (법률 프리미엄) |
| 추천 | ⭐⭐⭐ **전환 의도가 8개 중 가장 뾰족하다** |

**이 주제의 핵심 성질:** 검색자가 **이미 분쟁 중**이다. "집주인이 보증금을 안 준다"를
검색하는 사람은 광고를 무시하지 않는다 — 해결에 돈을 쓸 준비가 되어 있다.

**그리고 결정적 이점:** 로톡·법무법인 글은 **상담으로 유도하려고 일부러 결론을 안 준다.**
끝까지 답해 주는 글이 이기는 구조다.

## 1. 벤치마크

### 한국

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **easylaw.go.kr** (찾기쉬운 생활법령정보) | **이 주제의 교과서.** 법 조문을 생활 질문으로 바꿔 답하는 구조. 우리는 여기에 "실제 사례 분기"를 더한다 |
| **lawtalk.co.kr** (로톡) | 상위를 많이 잡고 있다. 배울 것: 질문 형태 제목. **안 하는 것: 결론 주기** — 그 자리가 우리 것이다 |
| **한국부동산원·LH 임대차분쟁조정위원회** (adrhome.reb.or.kr) | 조정 절차 원문 출처. 인용하면 신뢰 신호 |
| **대한법률구조공단** (hldcc.or.kr) | 무료 구조 제도. **"돈 없이 해결하는 법"** 각도의 재료 |

### 영어권

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **nolo.com** | 법률 정보 사이트의 세계 표준. **"이런 경우 / 저런 경우" 분기**와 서식 제공이 무기 |
| **legalzoom.com** (learn 섹션) | 서비스형이지만 정보 콘텐츠로 트래픽을 만든다. **서식·템플릿 배포**로 링크를 모으는 전략 |
| **findlaw.com** | 대형. 법 개념을 계층으로 정리하는 **정보 구조(IA)** 참고 |

### 베끼지 않을 것

- **법률 자문 제공.** 변호사법 위반이다. "일반 정보 + 절차 안내"까지만.
- 로톡식 **상담 연결 CTA.** 광고 모델과 충돌하고, 우리 차별점(끝까지 답함)을 스스로 지운다.

## 2. 사이트 설계

**사이트명 후보:** 분쟁기준 / 보증금닷 / 내용증명 / 싸우기전에
**태그라인:** "싸우기 전에 알아야 할 기준"

**카테고리 6개**

| 카테고리 | 슬러그 | 다루는 것 |
|---|---|---|
| 보증금 | `deposit` | 반환, 지연이자, 임차권등기 |
| 계약·갱신 | `contract` | 갱신청구권, 묵시적 갱신, 특약 |
| 수리·하자 | `repair` | 수선의무, 누수, 곰팡이, 원상복구 |
| 소송·조정 | `dispute` | 지급명령, 소액소송, 조정위 |
| 서식·문서 | `forms` | 내용증명, 계약서, 확정일자 |
| 이웃·생활 | `neighbor` | 층간소음, 주차, 반려동물 |

## 4. 수익 모델

1. **애드센스** — 법률 단가. 부동산·이사·보험 광고가 붙는다.
2. **서식 배포** — 내용증명·계약서 템플릿을 무료 배포하면 **자연 링크**가 붙는다(영어권 nolo 전략).
3. **제휴** — 전세보증보험, 법률구조 관련. 조심스럽게.

## 5. 이 주제의 함정

- **변호사법.** 개별 사건에 대한 법률 자문·대리는 불가. "이렇게 하면 이깁니다"는 금지. **절차와 판단 기준까지만.**
- **판례를 단정 인용하면 위험하다.** 사실관계가 다르면 결론도 다르다. "유사 사안에서 법원은 ~로 판단한 예가 있다"로 쓴다.
- **법 개정**(주택임대차보호법)이 자주 있다. 시행일 표기 필수.
- 이사철 편중이 있어 **비수기 대비**가 필요하다 → 이웃·생활 분쟁 카테고리가 그 역할.

## 6. 6개월 목표와 매각 값

- 6개월 월 **1.5만~4만 PV**, 월 **35만~140만원**
- 매각 시: 월 80만원이면 대략 **2,400만~3,200만원**
- **서식 배포로 링크가 붙으면** 도메인 신뢰가 빠르게 올라 다른 주제보다 오래 간다

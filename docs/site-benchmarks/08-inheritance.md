# 08. 상속·증여

> **"물려받을 때 뜯기지 않는 기준."**
> 상속세·증여세·유류분·상속포기·재산분할. **단가 최상, 검색량 최소.** 소수정예형.

## 0. 판정

| 항목 | 값 |
|---|---|
| 광고 단가 | **최상** — 금융+법률 교집합. CPC가 8개 중 가장 높은 축 |
| 검색량 | **8개 중 최소.** 대신 검색자 한 명의 가치가 가장 크다 |
| 진입 난이도 | **상** — 법무법인·세무법인이 상위를 잡고 있다 |
| 매각 배수 | 35~45배 (금융·법률 프리미엄) |
| 추천 | ⭐⭐ **PV로 이기는 주제가 아니다.** 적은 트래픽으로 높은 단가를 받는 구조 |

**이 주제의 핵심 성질:** 검색량이 작아도 **한 건이 수억짜리 의사결정**이라 광고 단가가 극단적으로 높다.
그리고 **부모가 살아 있을 때 검색하는 사람**(사전 증여)과 **돌아가신 뒤 검색하는 사람**(상속·유류분)이
완전히 다른 두 관객이다 — 사이트를 그 둘로 나눠 설계해야 한다.

## 1. 벤치마크

### 한국

- **세무·법률 자문.** 개별 상담은 자격 문제가 된다. 정보와 계산 구조까지만.
- 법무법인의 **사건 수임 CTA.** 광고 모델과 충돌한다.

## 2. 사이트 설계

**사이트명 후보:** 상속기준 / 물려받기전에 / 유류분닷 / INHERIT
**태그라인:** "물려받을 때 뜯기지 않는 기준"

**카테고리 6개**

| 카테고리 | 슬러그 | 다루는 것 |
|---|---|---|
| 상속세 | `inheritance-tax` | 세율, 공제, 신고 기한, 분할납부 |
| 증여세 | `gift-tax` | 공제 한도, 10년 합산, 차용증 |
| 유류분 | `forced-share` | 청구 요건, 계산, 기한 |
| 상속 절차 | `procedure` | 상속포기·한정승인, 재산 조회 |
| 재산 분할 | `division` | 협의분할, 기여분, 분쟁 |
| 사전 준비 | `planning` | 유언장, 사전증여 전략 |

## 4. 수익 모델

1. **애드센스** — 검색량은 적어도 클릭 단가가 최상위. **PV 대비 수익이 8개 중 1위.**
2. **계산기** — 상속세·증여세 계산기가 이 주제의 최강 유입 도구다.
3. **제휴** — 법무·세무 플랫폼. 신중히.

## 5. 이 주제의 함정

- **검색량이 작다.** 8개 중 트래픽이 가장 늦게 붙는다. 단독 사이트로는 성장이 느려
  **01번(세금)의 하위 카테고리로 시작해 떼어내는** 방식도 검토할 만하다.
- **세법 개정이 잦다**(공제 한도·세율). 매년 전수 갱신 필요.
- **가족 분쟁 주제라 감정적으로 민감하다.** 자극적 제목은 신뢰를 깎는다.
- **계산 오류가 치명적이다.** 세액 예시는 반드시 근거 조문·기준 연도를 병기한다.
  앱의 근거 장부(fact-guard)를 반드시 켜고 쓸 것.

## 6. 6개월 목표와 매각 값

- 6개월 월 **5천~1.5만 PV** (8개 중 최소)
- 그러나 단가가 높아 월 **30만~120만원** — **PV 효율은 1위**
- 매각 시: 월 80만원이면 **2,800만~3,600만원**

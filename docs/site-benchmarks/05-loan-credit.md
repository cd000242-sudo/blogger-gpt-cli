# 05. 대출·신용회복

> **"돈이 급할 때 손해 덜 보는 기준."**
> 정책서민금융·신용점수·개인회생·채무조정. **단가 1위, 난이도도 1위.**

## 0. 판정

| 항목 | 값 |
|---|---|
| 광고 단가 | **최상.** 금융·은행 영어권 RPM $65~110. 국내에서도 대출 광고가 최고 단가 |
| 검색량 | 큼 · 연중 고름 |
| 진입 난이도 | **상** — 금융사·대부중개가 돈을 쏟아붓는 판. 규제도 가장 세다 |
| 매각 배수 | **35~50배** (금융은 배수 프리미엄이 가장 크다) |
| 추천 | ⭐⭐ **수익은 최고, 위험도 최고.** 8개 중 마지막에 손대기를 권한다 |

**이 주제의 핵심 성질:** 단가가 높은 이유는 **뒤에 돈을 버는 사람이 많아서**다.
그만큼 경쟁이 세고, 광고성·불법 중개와 섞이기 쉬워 **정책 위반 위험이 8개 중 가장 크다.**

## 1. 벤치마크

### 한국

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **서민금융진흥원 / 신용회복위원회** (공식) | 제도 원문. 이들이 안 하는 것: **"나는 되나"의 사전 판정** |
| **banksalad.com** | 신용점수·대출 콘텐츠의 국내 최강. **"내 점수로 가능한 것"으로 개인화**하는 각도가 핵심 |
| **toss.im/tossfeed** | 금융 개념을 **한 문장으로 정의하고 시작**하는 방식. 우리 결론 블록과 정확히 같은 구조 |

### 영어권

| 사이트 | 무엇을 배울 것인가 |
|---|---|
| **nerdwallet.com** | 이 분야 세계 1위. CPA·리드젠 모델. **비교표 + 조건 필터**가 무기 |
| **creditkarma.com** | 신용점수를 **무료 도구로 잡고 대출로 태우는** 구조. 도구가 트래픽을 만든다 |
| **moneycrashers.com** | 개인이 시작해 키운 사례. **주제 폭이 넓어도 신뢰로 버틴** 케이스 |

### 베끼지 않을 것

- **대출 중개·연결.** 국내는 대부중개업 등록이 필요하다. 무등록 중개는 형사처벌 대상이다.
- "무직자 대출", "당일 승인" 류 키워드. **불법 사금융 인접**이라 애드센스 계정 자체가 위험해진다.
- 특정 상품 **추천·유도.** 정보 제공선을 넘지 않는다.

## 2. 사이트 설계

**사이트명 후보:** 신용기준 / 빚줄이기 / CREDITBASE / 대출전에
**태그라인:** "빌리기 전에 알아야 할 기준"

**카테고리 6개**

| 카테고리 | 슬러그 | 다루는 것 |
|---|---|---|
| 신용점수 | `score` | 산정 원리, 올리는 법, 조회 영향 |
| 정책금융 | `policy-loan` | 햇살론, 새출발기금, 최저신용자 |
| 채무조정 | `debt-relief` | 신복위 워크아웃, 개인회생, 파산 |
| 주택금융 | `mortgage` | 디딤돌, 버팀목, 보금자리론 |
| 카드·연체 | `card` | 리볼빙, 연체 기록, 채권추심 |
| 금융 상식 | `basics` | DSR, LTV, 금리 구조 |

## 4. 수익 모델

1. **애드센스** — 단가 최상. 다만 **광고 자체가 대부업 광고일 수 있어** 필터링을 걸어야 한다.
2. **비교 제휴** — 등록된 플랫폼 제휴만. 직접 중개는 하지 않는다.
3. **도구** — 신용점수·DSR 계산기가 트래픽과 체류를 동시에 만든다.

## 5. 이 주제의 함정 (8개 중 가장 위험하다)

- **무등록 중개는 범죄다.** 대출을 소개하고 대가를 받으면 대부중개업 등록이 필요하다. **정보만 다룬다**는 선을 절대 넘지 않는다.
- **애드센스 정책 위험.** "즉시 대출", "무직자 가능" 류는 계정 정지 사유가 될 수 있다. 키워드 블랙리스트를 앱에 걸어 둘 것.
- **YMYL 최상위 + 금융 규제.** 저자 자격, 근거 기관, 기준일이 없으면 순위도 안 붙고 신뢰도 안 생긴다.
- **금리·한도는 수시로 바뀐다.** 숫자를 박아 두면 금방 틀린다. "○년 ○월 기준"을 반드시 병기(앱의 결론 블록 `basis`가 이 역할).
- **경쟁자가 돈을 쓴다.** 개인 사이트가 정면으로 이기기 어렵다 → **"조건 판정"과 "불이익"** 각도로 우회한다. 금융사는 불이익을 안 쓴다.

## 6. 6개월 목표와 매각 값

- 경쟁이 세서 트래픽은 늦게 붙는다. 6개월 월 **1만~3만 PV**
- 대신 단가가 높아 월 **50만~200만원** 가능
- 매각 시: 월 100만원이면 **3,500만~5,000만원** (금융 배수 프리미엄이 가장 크다)
- **8개 중 만들기는 마지막, 팔 때 값은 1등**인 주제다

# 주제별 벤치마크 사이트 설계서

> 2026-08-26 조사. CLAIMWISE(leadernam.com)를 gardenbom.com 벤치마킹으로 만든 그 과정을,
> **주제만 바꿔 반복할 수 있게** 8개로 쪼개 둔 것.
> 각 파일은 "이대로 만들면 되는" 설계서다 — 사이트명·카테고리·URL 구조·첫 30편 키워드까지 들어 있다.

## 왜 이 8개인가

돈이 되는 주제는 **광고 단가가 정해져 있다.** 2026년 실측 기준으로:

| 분야 | 영어권 RPM | 배수(일반 대비) |
|---|---|---|
| 금융·은행 | $65~110 | 3.0× |
| 보험 | $40~80 (CPC $3.80) | 2.4× |
| 법률(특히 상해·전문분야) | $80+ | 2.3× |
| 부동산 | 높음 (매각 배수도 프리미엄) | — |
| 일반 생활정보 | $2~8 | 1.0× |

여기 8개는 전부 **금융·보험·법률·부동산 안**에 있다. 요리·여행·연예처럼 트래픽은 쉬워도
단가가 1/10인 주제는 넣지 않았다. 같은 노력에 수익이 10배 차이 난다.

그리고 8개 모두 **한국 제도 기반**이라 사장님 발행 파이프(네이버·티스토리·WP)가 그대로 돈다.

## 만들어서 파는 값 — 계산해 두자

콘텐츠 사이트는 **월 순익의 24~40배**에 팔린다(2026년 실측).

- Empire Flippers 평균 **33.2배**
- Flippa 평균 **24.6배**
- 디스플레이 광고형 평균 **34.6배**
- 금융·법률·부동산 같은 프리미엄 분야는 **배수 자체가 더 높게** 매겨진다

즉 **월 50만원 버는 사이트 = 대략 1,200만~2,000만원**이다.
사이트 8개를 각각 월 50만원까지 올리면 자산 가치가 1억을 넘는다.

**다만 트래픽 0인 신규 사이트는 팔리지 않는다.** 배수는 *순익*에 곱하는 것이라
순익이 0이면 값도 0이다. 파는 걸 목표로 한다면 최소 **6개월 수익 이력**이 필요하다.
그래서 이 설계서들은 전부 "6개월 안에 수익이 나는 구조"로 짜여 있다.

## 공통 규칙 (8개 전부에 적용)

CLAIMWISE에서 이미 확인한 것들이라 새 사이트에서 반복하지 않는다.

1. **단일 대주제.** 주제 밖 글은 전문성 신호를 깎는다. 애매하면 뺀다.
2. **카테고리 5~6개.** 벤치마크들이 전부 이 범위다.
3. **URL에 카테고리 포함**(`/%category%/%postname%/`).
4. **고정 페이지 4종 필수** — 소개·연락처·개인정보처리방침·면책. 없으면 애드센스 정책 위반이다.
5. **저자 실명·소개·스키마.** YMYL 주제는 이게 없으면 순위가 안 오른다.
6. **하루 2~3편.** 물량은 평균 참여도를 희석해 사이트 전체 신호를 약화시킨다.
7. **결론부터 블록**(v3.8.559)과 **독자 확보 블록**(v3.8.560)은 앱이 자동으로 넣는다.

## 이 설계서가 답하지 않는 것

- **어느 사이트가 실제로 얼마를 버는지**는 확인할 수 없었다. Semrush API 유닛이 없어
  트래픽 실측을 못 했다. 벤치마크는 "구조를 베낄 대상"이지 "수익이 검증된 대상"이 아니다.
- **경쟁 강도의 정확한 수치**도 마찬가지다. 진입 난이도는 SERP를 눈으로 본 판단이다.
- 시작 전에 각 주제의 키워드 5개를 직접 검색해 **관공서가 상위 3개를 덮고 있는지** 보는 게 좋다.
  덮고 있으면 그 각도는 피한다(CLAIMWISE에서 이미 쓰는 규칙).

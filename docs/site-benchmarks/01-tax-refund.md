# 01. 세금·환급

> **"내가 더 낸 세금을 돌려받는 기준."**
> 연말정산·종합소득세·경정청구·지방세. 직장인과 프리랜서 전원이 매년 두 번 검색한다.

## 0. 판정

| 항목 | 값 |
|---|---|
| 광고 단가 | **최상** (금융 계열, 영어권 RPM $65~110 / 국내 보험·금융 RPM 1만~3만원대) |
| 검색량 | 매우 큼, 단 **계절형** — 1~3월(연말정산)·5월(종소세)에 집중 |
| 진입 난이도 | **중** — 국세청이 상위를 덮지만 문서가 불친절해 해설 수요가 크다 |
| 매각 배수 | 30~40배 (금융 프리미엄) |
| 추천 | ⭐⭐⭐ **1순위.** 달력이 트래픽을 밀어준다 |

**이 주제의 핵심 성질:** 트래픽이 **날짜에 묶여 있다.** 1월에 준비하고 2월에 터진다.
5월도 같다. 즉 **비수기에 글을 쌓고 성수기에 거둔다** — 지금(8월) 시작하면 1월까지 딱 맞다.

- 대형 사이트의 **세무 상담 유도**. 상담 리드젠은 진입 장벽이 다르다.

## 2. 사이트 설계

**사이트명 후보:** 세금돌려받기 / TAXBACK / 환급기준 / 더받는연말정산

| 카테고리 | 슬러그 | 다루는 것 |

## 4. 수익 모델

1. **애드센스** — 주 수익. 금융 단가를 그대로 받는다.
2. **제휴** — 세무 대행 서비스(삼쩜삼 등) 제휴가 있으면 붙인다. 단 **정보 신뢰를 해치지 않는 선**에서.
3. **비수기 대책** — 3·4월과 6~10월은 트래픽이 꺼진다. 지방세(6·9월 재산세, 12월 자동차세)로 메운다.

## 5. 이 주제의 함정

- **매년 제도가 바뀐다.** 작년 글을 방치하면 틀린 정보가 된다. 연 1회 갱신이 필수고, 이게 곧 진입장벽이다(경쟁자도 똑같이 힘들다).
- **YMYL 최상위.** 저자 실명·자격·근거 기관·기준일이 없으면 순위가 안 붙는다.
- **국세청이 상위를 덮는 키워드**는 피한다. 대신 "국세청 문서를 읽고도 모르는 것"을 노린다 — 예: "부양가족 중복 공제하면 어떻게 되나".
- **금액을 지어내면 치명적이다.** 앱의 근거 장부(fact-guard)가 이미 이걸 막고 있다. 반드시 켜고 쓴다.

## 6. 6개월 목표와 매각 값

- 6개월(≈540편)에 월 **1만~3만 PV** 목표 → 금융 RPM 기준 월 **20만~90만원**
- 매각 시: 월 50만원이면 대략 **1,200만~2,000만원** (24~40배)
- 매각을 노린다면 **2월 성수기 실적이 포함된 12개월 이력**이 값을 가장 높인다

> 템플릿이 실제로 되는지 보여주는 예이자, 신규 사이트의 기준점이다.
> 2026-08-26 실측 기준. 사이트: leadernam.com · 글 248편 · 색인 정상

## 1. 정체

```yaml
사이트명:      CLAIMWISE
태그라인:      보험금·지원금·환급, 돈 돌려받는 기준
도메인:        leadernam.com
한 줄 정의:    받을 수 있는데 못 받고 넘어가는 돈의 기준을 알려주는 곳
```

> 도메인과 사이트명이 다르다(leadernam ↔ CLAIMWISE). 감수하고 간다 —
> 로고·소셜·퍼블리셔센터를 전부 CLAIMWISE 로 통일해 상쇄했다.
> **신규 사이트는 처음부터 도메인과 이름을 맞춘다.**

## 2. 판정

| 항목 | 값 | 메모 |
|---|---|---|
| 광고 단가 | **최상** | 보험·금융. 국내 RPM 1만~3만원대 |
| 검색량 | 큼 · 상시형 | 제도 발표 때 급증 |
| 진입 난이도 | 중 | 관공서가 상위를 덮지만 문서가 불친절해 해설 수요가 크다 |
| YMYL | **예** | 저자·근거·기준일 전부 필수 |
| 수익 모델 | 애드센스 단독 | 제휴는 아직 없음 |

**검증된 규칙:** 관공서가 상위 3개를 덮은 키워드는 버린다.
대신 **"관공서 문서를 읽고도 모르는 것"** 을 노린다.

## 10. 이 사이트에서 배운 것 (신규 사이트에 그대로 적용)

1. **주제 밖 글은 뺀다.** 동떨어진 17편을 휴지통으로 옮겼다 — 애매하면 뺀다
2. **태그를 남발하면 크롤 예산이 죽는다.** 고아 태그 2,395개가 색인을 막고 있었다. 글당 태그 5개 상한
3. **카테고리 재배정은 301이 자동으로 붙는다**(WP 기본). 다만 수정일이 갱신된다
4. **고정 페이지 4종이 없으면 애드센스 정책 위반**이다. 처음부터 만든다
5. **Yoast 사이트명과 홈 title 은 따로 고쳐야 한다** — WP 설정만 바꾸면 옛 이름이 남는다

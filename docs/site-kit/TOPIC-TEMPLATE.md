## 2. 판정 (만들기 전에 스스로 답한다)

| 항목 | 값 | 메모 |
|---|---|---|
| 광고 단가 | 최상/상/중/하 | 금융·보험·법률·부동산 = 상위 / 생활·연예 = 하위 |
| 검색량 | | 계절형인지 상시형인지 함께 적는다 |
| 진입 난이도 | | 상위 3개를 관공서·대형 플랫폼이 덮고 있는가 |
| YMYL 여부 | 예/아니오 | 예면 저자·근거·기준일이 **필수**가 된다 |
| 수익 모델 | | 애드센스 단독인지 제휴가 붙는지 |

**시작 전 30분 검증:** 대표 키워드 5개를 직접 검색한다.
상위 3개를 관공서·대형 플랫폼이 덮고 있으면 **그 각도는 버리고** 다른 각도를 찾는다.

## 6. 스킨·말투

```yaml
테마 프리셋:    # 푸드 / 금융 / 뉴스 / 건강 / 라이프 / 미니멀
말투:           # 친근·리뷰형 / 정중·정보형 / 전문·분석형
하루 발행 수:   # 2~3편 권장. 늘리면 평균 신호가 희석된다
홈 배치:        # 잡지형(보기 좋음) / 목록형(색인 유리) / 카드형
이미지:         # AI 생성 / 실사 필수 / 혼합
```

> **주의:** 여행·음식·제품 리뷰는 **실사진이 랭킹 요소**다. AI 생성컷은 역신호가 된다.
> 그런 주제는 `이미지: 실사 필수` 로 두고, 확보 방법까지 여기 적는다.

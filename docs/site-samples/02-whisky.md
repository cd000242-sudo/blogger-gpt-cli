# 02. 위스키·와인

> **"한 병 사기 전에 보는 곳."** 라벨에 안 적힌 걸 알려준다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **45** (라면=100). 12월 급증(56), 여름 하락 |
| 단가 | **중상** — 주류 광고는 제한되나 인접(선물·잔·냉장고)이 붙는다 |
| 스펙트럼 | **최상** — 증류소 수백 × 빈티지 × 가격대 × 안주 |
| 진입 | 중 — 커뮤니티(디시·클리앙)와 유튜브가 강하다 |
| 영어 확장 | 완벽 — whisky 리뷰는 영어권이 본진 |

## 스킨 — 짙은 차콜 + 황동

바 조명 아래의 인상. **어둡고, 금속 반사가 하나 있어야** 술처럼 보인다.
샘플 12개 중 **가장 어두운 축**이라 대비용으로 좋다.

```yaml
ground:    "#16130F"   # 짙은 갈색 섞인 검정
surface:   "#1F1B16"
ink:       "#EFE7DA"
muted:     "#9C9081"
accent:    "#C08A2E"   # 황동 — 위스키 색
accent2:   "#7A2B33"   # 와인 버건디
line:      "#2E2820"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Nanum Myeongjo 700 — **세리프.** 격을 만든다 |
| 본문 글꼴 | Gothic A1 400 / 16px |
| 숫자 | IBM Plex Mono — 도수·숙성연수·가격 |
| 모서리 | 3px (거의 각지게) |
| 이미지 비율 | **3:4 세로** — 병이 세로라서 |
| 배치 | 카드형, 어두운 배경에 병 사진이 뜨게 |

**이 주제만의 요소:** 테이스팅 노트를 **막대 게이지**로(스모키·단맛·바디). 글자보다 눈에 빠르다.

## 첫 12편

1. 5만원 이하 입문 위스키
2. 싱글몰트와 블렌디드 차이
3. 하이볼 황금 비율
4. 위스키 숙성연수의 실제 의미
5. 편의점에서 살 수 있는 위스키
6. 와인 당도 표기 읽는 법
7. 2만원대 데일리 와인
8. 위스키 잔 종류별 차이
9. 코르크 vs 스크류캡
10. 면세점 주류 한도와 계산
11. 개봉 후 보관 기간
12. 선물용 주류 고르는 기준

## 수익 · 주의

- 애드센스 + 제휴(잔·디캔터·냉장고). **주류 자체는 온라인 판매 제한**이라 주변 기기로 번다
- ⚠️ **주류 광고 규제** — 음주 조장 표현 금지, 연령 확인 문구 필요
- 커뮤니티가 강한 주제라 **"정리·비교"**로 차별한다(그들은 산발적이다)

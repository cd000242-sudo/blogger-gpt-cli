# 07. 자동차

> **"타기 전·팔기 전에 보는 곳."** 신차·정비·중고차·전기차.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **매우 큼** — 정기검사만 라면의 96 |
| 단가 | **상** — 보험·타이어·정비 광고 |
| 스펙트럼 | **최상** — 차종 수백 × 연식 × 정비 항목 × 전기차 |
| 진입 | 중상 — 매체·동호회가 강하다. **다만 정비 실측은 비어 있다** |
| 영어 확장 | 좋음 — 다만 차종·규정이 지역마다 다르다 |

> ⚠️ 행정 절차(정기검사 예약·과태료 납부)는 **관공서가 상위를 독점**한다.
> 그 각도는 버리고 **"안 받으면 얼마" "불합격하면 어떻게"** 같은 파생 질문으로 들어간다.

## 스킨 — 그래파이트 + 시그널 레드

**금속·기계의 인상.** 계기판 문법. 각지고 고정폭 숫자가 많다.

```yaml
ground:    "#EEEFF0"
surface:   "#FFFFFF"
ink:       "#15181A"
muted:     "#61686C"
accent:    "#C42B22"   # 시그널 레드
accent2:   "#2F4A5C"   # 계기 블루그레이
line:      "#D8DBDD"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 800 — 굵고 단단하게 |
| 본문 글꼴 | Gothic A1 400 / 16px |
| 숫자 | IBM Plex Mono — **연비·마력·비용이 전부 숫자다** |
| 모서리 | 3px |
| 이미지 비율 | 16:9 |
| 배치 | 목록형 + 스펙 비교표 |

**이 주제만의 요소:** **비용 표**(부품·공임·총액)를 정비 글마다 고정. 사람들이 찾는 건 결국 금액이다.

## 첫 12편

1. 엔진오일 교환 주기의 진실
2. 타이어 교체 시점 판단법
3. 브레이크 패드 교환 비용
4. 정기검사 불합격 항목과 재검사
5. 검사 안 받으면 과태료 얼마
6. 중고차 성능점검기록부 읽는 법
7. 침수차 확인 방법
8. 전기차 배터리 수명과 보증
9. 완속·급속 충전 비용 계산
10. 자동차세 연납 할인
11. 보험 할증 기준 금액
12. 첫차 유지비 1년 총액

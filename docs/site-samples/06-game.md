# 06. 게임

> **"막힌 데서 검색한다."** 공략·패치·스펙. 신작이 계속 나와 소재가 안 마른다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **매우 큼** — 신작 출시일에 폭증 |
| 단가 | **하** (2~5천원) — 광고주가 적다 |
| 스펙트럼 | **최상** — 게임 수천 × 패치 × 캐릭터 × 공략 |
| 진입 | 하 — 뚫리지만 **인벤·나무위키가 두껍다** |
| 영어 확장 | 완벽 — 다만 영어권은 경쟁이 훨씬 세다 |

## 스킨 — 블랙 + 바이올렛 네온

**12개 중 가장 어둡고 가장 빠른 인상.** 게임 UI 문법을 그대로 쓴다.

```yaml
ground:    "#0B0A10"
surface:   "#14121C"
ink:       "#EDEAF5"
muted:     "#8E88A6"
accent:    "#9B6BFF"   # 바이올렛 네온
accent2:   "#3BE0C0"   # 보조 시안 (버프·성공 표기)
line:      "#241F33"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 800 — 굵고 압축된 인상 |
| 본문 글꼴 | Gothic A1 400 / 15px (조밀하게) |
| 숫자 | IBM Plex Mono — **데미지·쿨타임·확률** |
| 모서리 | **2px** (가장 각지게) |
| 이미지 비율 | 16:9 — 게임 화면 그대로 |
| 배치 | 카드형, 조밀하게. 여백을 적게 |

**이 주제만의 요소:** **패치 diff 표**(이전 → 이후 수치). 게이머는 이것만 본다.

## 첫 12편

1. (대상 게임) 초반 진행 순서
2. 직업별 추천 빌드
3. 최신 패치 변경점 정리
4. 재화 효율 파밍 루트
5. 무과금 성장 로드맵
6. 옵션 설정 권장값
7. 프레임 떨어질 때 확인할 것
8. 컨트롤러 호환 설정
9. 신작 출시일·사양 정리
10. 서버 점검·오류 코드
11. 계정 연동·기기 이전
12. 환불 규정과 절차

## 수익 · 주의

- 단가가 낮아 **PV로만 이긴다.** 월 20만 PV 이상이 되어야 의미 있다
- ⚠️ **게임 스크린샷은 저작권**이다. 대개 관대하지만 상업적 이용은 확인 필요
- 한 게임에 올인하면 **그 게임이 죽을 때 사이트도 죽는다.** 3~5개 이상으로 분산
- 팬층 충성도가 높아 **재방문율은 12개 중 최상**

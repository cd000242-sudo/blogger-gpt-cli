# 04. 캠핑·아웃도어

> **"장비 사기 전에 보는 곳."** 비싼 걸 사기 전에 한 번 검색한다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | 중상 · **강한 계절형**(3~5월, 9~10월 성수기) |
| 단가 | 중 — 장비 제휴가 광고보다 크다 |
| 스펙트럼 | **상** — 장비 카테고리 × 계절 × 캠핑장 수천 곳 |
| 진입 | 중 — 유튜브가 강하지만 **글로 비교하는 곳은 적다** |
| 영어 확장 | 좋음 — 장비는 글로벌 브랜드 공통 |

## 스킨 — 흙빛 + 이끼

**거칠고 자연스럽게.** 매끈한 그라데이션을 쓰지 않는다.

```yaml
ground:    "#F2F0EA"   # 바랜 캔버스
surface:   "#FFFFFF"
ink:       "#20241C"
muted:     "#6B7060"
accent:    "#4A6141"   # 이끼 초록
accent2:   "#A8631F"   # 흙·불빛 주황
line:      "#DEDAD0"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 800 — 굵고 실용적 |
| 본문 글꼴 | Gothic A1 400 / 16px |
| 숫자 | IBM Plex Mono — 무게(g)·내수압(mm)·온도(℃) |
| 모서리 | 4px |
| 이미지 비율 | **16:9 와이드** — 풍경이 주인공 |
| 배치 | 잡지형 + 장비 비교표 |

**이 주제만의 요소:** **무게·부피·내한온도 3축 비교표.** 캠핑 장비 선택은 결국 이 셋이다.

## 첫 12편

1. 텐트 내수압 수치의 실제 의미
2. 4인 가족 텐트 고르는 기준
3. 침낭 내한온도 표기 함정
4. 자충 매트 두께별 체감
5. 화로대 재질 차이
6. 캠핑 전기용량 계산
7. 겨울 캠핑 난방 안전 수칙
8. 국립공원 야영장 예약 방법
9. 노지 캠핑 가능한 곳 기준
10. 캠핑 장비 첫 세트 예산별 구성
11. 우천 시 철수 판단 기준
12. 장비 보관·곰팡이 방지

## 수익 · 주의

- **제휴가 주 수익.** 장비 객단가가 높아 애드센스보다 클 수 있다
- ⚠️ **난방·화기 안전은 사람이 죽는 주제다.** 일산화탄소 경고를 반드시 명시
- 계절 편차가 커서 **비수기 대비**가 필요하다 → 실내·차박·백패킹으로 메운다

# 09. 육아·유아용품

> **"이게 정상인가."** 초보 부모는 하루에도 몇 번씩 검색한다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **매우 큼** — 월령별 검색이 끝없이 갱신된다 |
| 단가 | **중상** — 분유·기저귀·보험·교육 광고 |
| 스펙트럼 | **최상** — 월령 0~60개월 × 증상 × 용품 × 제도 |
| 진입 | 중 — 맘카페가 강하지만 **정리된 글은 부족하다** |
| 영어 확장 | 중 — 제도가 달라 용품·발달 부분만 넘어간다 |

## 스킨 — 파스텔 + 부드러운 청

**순하고 안전해 보여야 한다.** 채도를 낮춘 파스텔.
불안한 상태로 새벽에 보는 화면이라 **눈이 안 부시게** 명도를 조절한다.

```yaml
ground:    "#F6F7FA"
surface:   "#FFFFFF"
ink:       "#22262E"
muted:     "#6E7684"
accent:    "#5A87B8"   # 부드러운 청
accent2:   "#D8896F"   # 따뜻한 살구 (강조 최소)
line:      "#E4E8EF"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 700 |
| 본문 글꼴 | Gothic A1 400 / **17px** (큰 편) / 행간 1.85 |
| 모서리 | 12px (둥글게) |
| 이미지 비율 | 4:3 |
| 배치 | 목록형. 월령 필터가 상단에 |

**이 주제만의 요소:** 글머리에 **월령 배지**(예: 6~9개월). 부모는 자기 아이 월령만 본다.
그리고 **"병원 가야 하는 신호"** 박스를 증상 글마다 고정 — 이게 신뢰를 만든다.

## 첫 12편

1. 신생아 수유량 기준
2. 이유식 시작 시기와 순서
3. 통잠 자는 시기와 수면 교육
4. 열날 때 병원 가야 하는 기준
5. 예방접종 스케줄 정리
6. 기저귀 사이즈 갈아탈 시점
7. 분유 단계별 차이
8. 아기 피부 트러블 구분
9. 카시트 장착 기준과 시기
10. 부모급여·아동수당 신청
11. 어린이집 입소 대기 전략
12. 응급실 가기 전 확인할 것

## 수익 · 주의

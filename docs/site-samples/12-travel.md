# 12. 국내여행

> **"가기 전에 확인할 것."** 지역 × 계절 × 테마로 끝없이 갈라진다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **매우 큼** — 주말·연휴 직전 급증 |
| 단가 | 중 — 숙박·렌터카 제휴가 광고보다 크다 |
| 스펙트럼 | **최상** — **229개 시군구** × 계절 × 테마 × 동반자 |
| 진입 | 중 — 대형 플랫폼이 예약을 쥐지만 **"실제로 가보면 어떤지"는 비어 있다** |
| 영어 확장 | **최상** — K-컬처 붐. 외국인이 찾는 한국 여행 정보는 수요가 크다 |

> 229개 시군구 × 테마 5개 = **1,000개 이상의 페이지**가 구조적으로 나온다.
> 스펙트럼만 보면 12개 중 가장 넓다.

## 스킨 — 하늘 + 산호

**12개 중 가장 밝고 넓다.** 사진이 크고 UI 가 가볍다.

```yaml
ground:    "#F4F8FA"
surface:   "#FFFFFF"
ink:       "#17242B"
muted:     "#5F757F"
accent:    "#2C7FA8"   # 하늘·바다
accent2:   "#E8724C"   # 산호 (강조·지도 핀)
line:      "#DDE7EC"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 700 |
| 본문 글꼴 | Gothic A1 400 / 16px / 행간 1.8 |
| 모서리 | 10px |
| 이미지 비율 | **16:9 와이드, 풀블리드 히어로** |
| 배치 | 잡지형 + 지역 필터 상단 고정 |

**이 주제만의 요소:** **실용 박스**(주차·입장료·소요시간·화장실·유모차 가능)를 장소 글마다 고정.
플랫폼이 절대 안 적는 정보이고, 사람들이 진짜 궁금해하는 것이다.

## 첫 12편

1. (지역) 주차 무료인 관광지
2. 아이와 갈 만한 실내 명소
3. 우천 시 대체 코스
4. 당일치기 코스 시간표
5. 숙소 체크인 전 짐 맡기는 법
6. 렌터카 보험 선택 기준
7. 축제 기간 교통 통제 정보
8. 성수기 숙박 예약 시점
9. 반려동물 동반 가능 시설
10. 무장애·유모차 접근 가능 코스
11. 지역 특산물 실제 가격대
12. 관광지 입장료 할인 방법

## 수익 · 주의

- 애드센스(중) + **숙박·렌터카·투어 제휴**(Klook·야놀자·아고다)
- ⚠️ **실사진이 랭킹 요소다.** 여행은 AI 생성컷이 가장 크게 역신호로 작동한다.
  실사 확보 방법을 정하지 않으면 **이 주제는 시작하지 않는다**
- 정보가 빨리 낡는다(휴관·요금 인상) — 갱신 주기를 짧게 잡는다

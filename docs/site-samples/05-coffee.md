# 05. 커피·홈카페

> **"집에서 제대로 내리는 법."** 원두·기구·레시피가 끝없이 나온다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | 큼 · 연중 균일 |
| 단가 | 중 — 기구·원두 제휴 |
| 스펙트럼 | **최상** — 원산지 × 로스팅 × 추출법 × 기구 |
| 진입 | 중 — 카페 매체가 있으나 **홈카페 실측은 비어 있다** |
| 영어 확장 | 완벽 — coffee 는 영어권 거대 니치 |

## 스킨 — 로스팅 브라운 + 크림

**차분하고 따뜻하게.** 채도를 낮춘다. 카페 인테리어의 인상.

```yaml
ground:    "#F5F1EC"
surface:   "#FFFFFF"
ink:       "#241C16"
muted:     "#75665B"
accent:    "#7A4A25"   # 로스팅 브라운
accent2:   "#B98A4B"   # 크레마
line:      "#E5DDD3"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Nanum Myeongjo 700 — 세리프. 손맛의 인상 |
| 본문 글꼴 | Gothic A1 400 / 16px / 행간 1.8 |
| 숫자 | IBM Plex Mono — **비율(1:16)·온도·시간이 핵심 데이터** |
| 모서리 | 8px |
| 이미지 비율 | 1:1 — 잔·드리퍼가 정사각에 맞는다 |
| 배치 | 잡지형, 여백 넓게 |

**이 주제만의 요소:** **레시피 카드**(원두g·물g·온도·시간·분쇄도)를 고정 규격으로. 그대로 따라 하게.

## 첫 12편

1. 핸드드립 물 온도와 맛의 관계
2. 분쇄도 단계별 차이
3. 원두 로스팅 단계 읽는 법
4. 드리퍼 종류별 맛 차이
5. 커피 비율 1:15 vs 1:17
6. 모카포트 사용법과 실패 원인
7. 에어로프레스 레시피
8. 콜드브루 침출 시간
9. 원두 보관 방법과 산패
10. 홈카페 입문 장비 예산별
11. 캡슐커피 호환성 정리
12. 디카페인 공정 차이

## 수익 · 주의

- 애드센스 + **기구·원두 제휴**. 반복 구매 품목이라 제휴가 꾸준하다
- 경쟁이 카페 매체·유튜브에 몰려 있어 **"수치로 재는 글"**이 빈자리다
- 사진이 중요한 주제 — 실사 확보 방법을 정해두고 시작한다

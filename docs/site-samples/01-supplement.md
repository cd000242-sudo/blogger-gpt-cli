# 01. 영양제·건강기능식품

> **"성분표를 읽어 주는 곳."** 뭘 먹어야 하는지가 아니라, 뭐가 다른지를 알려준다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **96** (라면=100). 연중 78~91 로 거의 안 흔들린다 |
| 단가 | **상** — 건강 계열 |
| 스펙트럼 | **최상** — 성분 40종 × 목적 15 × 대상 8 = 조합 수천 |
| 진입 | **뚫린다** — 상위 5개 중 개인 사이트 2개(아이허브 제휴형) |
| 영어 확장 | 완벽 — supplements 는 영어권 최대 제휴 니치 중 하나 |

## 스킨 — 임상적 화이트 + 청록

병원 검사지의 인상. **차갑고 정확해 보여야 신뢰가 생긴다.** 감성은 뺀다.

```yaml
ground:    "#F4F7F7"   # 아주 옅은 청회색
surface:   "#FFFFFF"
ink:       "#12211F"
muted:     "#5E7472"
accent:    "#0E7C6B"   # 청록 — 의료·검사의 색
warn:      "#B06A12"   # 성분 주의 표기
line:      "#DCE5E4"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 **700** — 장식 없는 그로테스크 |
| 본문 글꼴 | Gothic A1 400 / 16px / 행간 1.75 |
| 숫자 | IBM Plex Mono — **함량·mg 은 반드시 고정폭** |
| 모서리 | 6px (각지지도 둥글지도 않게) |
| 이미지 비율 | **1:1** — 제품컷이 정사각이라 |
| 배치 | 목록형. 성분 비교표가 주인공 |

**이 주제만의 요소:** 글마다 **성분 스펙 표**(형태·흡수율·권장량·주의)를 고정 배치.
표가 곧 콘텐츠다 — 인용도 표에서 나온다.

## 첫 12편

1. 마그네슘 종류별 차이 (산화·구연산·글리시네이트)
2. 오메가3 rTG vs EE 흡수율
3. 비타민D 하루 권장량과 과잉 기준
4. 루테인·지아잔틴 비율
5. 밀크씨슬 실리마린 함량 보는 법
6. 프로바이오틱스 균주 표기 읽는 법
7. 종합비타민이 필요한 사람·아닌 사람
8. 철분제 먹는 시간과 흡수 방해 음식
9. 콜라겐 저분자 표기의 실제 의미
10. 영양제 함께 먹으면 안 되는 조합
11. 임산부가 피해야 할 성분
12. 유통기한 지난 영양제

## 수익 · 주의

- 애드센스(건강 단가) + **아이허브·쿠팡 제휴**. 제휴가 광고보다 클 수 있다
- ⚠️ **건강기능식품 표시·광고 규제.** 효능 단정 금지 — "치료한다" 못 쓴다.
  **"성분별 차이·흡수율·고르는 법"** 각도로 가면 규제를 피하면서 검색 의도와도 맞는다
- YMYL 이라 저자·근거·기준일 필수

# 08. 인테리어·홈스타일링

> **"고치기 전에 보는 곳."** 시공 견적부터 셀프 시공까지.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | 큼 · 이사철(2~3월, 9~10월) 급증 |
| 단가 | **상** — 시공·가구 객단가가 높아 광고주가 붙는다 |
| 스펙트럼 | **상** — 공간 × 시공 항목 × 예산대 × 평형 |
| 진입 | 중 — 오늘의집이 강하지만 **견적·하자 각도는 비어 있다** |
| 영어 확장 | 중 — 주거 형태가 달라 그대로는 안 넘어간다 |

## 스킨 — 오프화이트 + 모래

**12개 중 여백이 가장 넓다.** 사진이 주인공이라 UI 를 최대한 지운다.

```yaml
ground:    "#F7F5F1"
surface:   "#FFFFFF"
ink:       "#22201D"
muted:     "#7C766D"
accent:    "#9A7B54"   # 모래·우드
accent2:   "#41504A"   # 짙은 세이지
line:      "#E7E2DA"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Nanum Myeongjo 400 — **얇은 세리프.** 굵으면 사진을 이긴다 |
| 본문 글꼴 | Gothic A1 300 / 16px / 행간 1.9 |
| 모서리 | 0px — **각지게.** 건축의 인상 |
| 이미지 비율 | **16:9 와이드, 풀블리드** |
| 배치 | 잡지형. 여백 최대 |

**이 주제만의 요소:** **견적 범위 표**(항목·평당 단가·총액 범위). 업체가 절대 먼저 안 알려주는 것.

## 첫 12편

1. 도배 평당 단가 범위
2. 장판 vs 마루 비용·수명
3. 욕실 리모델링 총액 구성
4. 샷시 교체 비용과 시기
5. 셀프 페인팅 준비물과 실패 원인
6. 조명 색온도 고르는 기준
7. 전세집에서 가능한 시공
8. 시공 견적서 항목 읽는 법
9. 하자 발생 시 보수 요구 절차
10. 곰팡이 원인별 대처
11. 평형별 가구 배치 기준
12. 인테리어 업체 고를 때 확인할 것

## 수익 · 주의

- 애드센스 + **가구·자재 제휴**(객단가 높음). 시공 리드젠은 규제 확인 필요
- ⚠️ **전기·가스·철거는 자격이 필요하다.** "셀프로 하세요"라고 쓰면 안 되는 항목이 있다
- 사진이 곧 경쟁력 — **실사 확보가 안 되면 이 주제는 하지 않는다**

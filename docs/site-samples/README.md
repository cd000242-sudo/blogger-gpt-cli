# 주제별 사이트 샘플 12종

> **이 폴더의 목적은 니치 리서치가 아니라 "보여주기"다.**
> 같은 엔진에 주제 .md 만 갈아끼우면 **스킨·색·글꼴·배치가 이렇게 달라진다**를 증명하는 샘플 묶음.
> 구조·SEO 규격은 [../site-kit/00-build-spec.md](../site-kit/00-build-spec.md) 에 있고 전 주제 공통이다.

## 왜 12개인가

시각적으로 최대한 먼 곳에 12개를 흩어 놓았다.
**어두운 것 / 밝은 것 / 따뜻한 것 / 차가운 것 / 두꺼운 것 / 얇은 것**이 다 들어가야
"아무 주제나 된다"가 눈으로 증명된다.

| # | 주제 | 스킨 한 줄 | 성격 |
|---|---|---|---|
| 01 | [영양제·건강기능식품](01-supplement.md) | 임상적 화이트 + 청록 | 차갑고 정확 |
| 02 | [위스키·와인](02-whisky.md) | 짙은 차콜 + 황동 | 어둡고 고급 |
| 03 | [반려동물](03-pet.md) | 크림 + 살구 | 따뜻하고 둥글다 |
| 04 | [캠핑·아웃도어](04-camping.md) | 흙빛 + 이끼 | 거칠고 자연 |
| 05 | [커피·홈카페](05-coffee.md) | 로스팅 브라운 + 크림 | 차분하고 향 |

> 13번만 성격이 다르다. **영어 사이트 전제**이고, 12개 중 유일하게 색 강조를 쓰지 않는다.
> 그리고 **자동화 친화도가 가장 높다** — 실사진이 필요 없어 툴로 돌리기에 가장 잘 맞는다.

## 각 .md 에 들어 있는 것

```
① 한 줄 정의        누구의 무엇을 다루는가
② 판정              단가 · 스펙트럼 · 진입 난이도
③ 스킨              팔레트 hex 6색 · 글꼴 2종 · 배치 · 이미지 톤   ← 이 폴더의 핵심
④ 카테고리 6개      이름 + 영문 슬러그
⑤ 첫 12편          발행 순서
⑥ 수익 · 주의
```

## 스킨이 실제로 갈리는 지점

주제가 바뀌면 색만 바뀌는 게 아니다. **네 가지가 같이 움직인다.**

| 요소 | 예 |
|---|---|
| **명도** | 게임·위스키는 어둡게, 육아·인테리어는 밝게 |
| **글꼴 무게** | 피트니스는 굵게(800), K-뷰티는 얇게(300) |
| **모서리** | 반려동물·육아는 둥글게(14px), 자동차·게임은 각지게(2px) |
| **이미지 비율** | 여행·인테리어는 와이드(16:9), 영양제·뷰티는 정사각(1:1) |

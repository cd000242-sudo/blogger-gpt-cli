# 03. 반려동물

> **"우리 애한테 뭐가 맞나."** 사료·병원비·행동, 보호자가 매일 검색한다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | 큼 (반려동물 장례만 따로 재도 라면의 8) |
| 단가 | **중상** — 펫보험·사료·병원 광고 |
| 스펙트럼 | **최상** — 견종·묘종 × 나이 × 증상 × 제품 |
| 진입 | 중 — 개인 블로그가 많아 뚫리나 그만큼 붐빈다 |
| 영어 확장 | 좋음 — 다만 견종·제품이 지역마다 다르다 |

## 스킨 — 크림 + 살구

**둥글고 따뜻하게.** 12개 중 모서리가 가장 둥근 쪽.
불안한 보호자가 보는 화면이라 각지면 안 된다.

```yaml
ground:    "#FBF6F0"
surface:   "#FFFFFF"
ink:       "#2B211B"
muted:     "#7A6A5E"
accent:    "#E0794A"   # 살구
accent2:   "#5C8D6A"   # 병원·건강 항목용 초록
line:      "#EDE2D6"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Jua 또는 Gothic A1 700 — **둥근 인상** |
| 본문 글꼴 | Gothic A1 400 / 16px / 행간 1.8 |
| 모서리 | **14px** (가장 둥글게) |
| 이미지 비율 | 4:3 — 동물 사진이 가로에 잘 맞는다 |
| 배치 | 잡지형. 사진이 커야 한다 |

**이 주제만의 요소:** 글머리에 **대상 배지**(견종/나이/체중)를 달아 "우리 애 얘기인지"를 즉시 판단하게.

## 첫 12편

1. 사료 원재료 표기 읽는 법
2. 강아지 나이별 사료 급여량
3. 고양이 신부전 초기 신호
4. 슬개골 탈구 등급과 수술 시점
5. 중성화 수술 비용과 회복
6. 펫보험 보장 범위 비교
7. 예방접종 스케줄
8. 분리불안 완화 훈련
9. 사람 음식 중 먹이면 안 되는 것
10. 반려동물 등록 절차·과태료
11. 장례 절차와 비용
12. 반려동물 데리고 갈 수 있는 곳

## 수익 · 주의

- 애드센스 + **사료·용품 제휴**(객단가 준수). 펫보험 제휴가 붙으면 단가가 크게 오른다
- ⚠️ **의료 조언으로 읽히면 안 된다.** "이 증상은 ○○병"은 금지 — "이럴 땐 병원에 간다"까지
- 사진이 핵심인 주제라 **AI 생성컷은 역신호**. 실사가 필요하다

# 11. K-뷰티

> **"성분 보고 사는 법."** 한국 화장품은 지금 전 세계가 찾는다.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | 큼 (국내 "화장품 성분"만 좁게 재면 라면의 2.6이지만, 제품·브랜드까지 넓히면 훨씬 크다) |
| 단가 | **중상** — 제휴가 광고보다 크다 |
| 스펙트럼 | **최상** — 성분 × 피부타입 × 제품군 × 브랜드, 신제품 무한 |
| 진입 | 중 — 화해·올리브영이 강하나 **성분 해설은 열려 있다** |
| 영어 확장 | **최상** — K-beauty 는 영어권 수요가 폭발 중. 한국인의 정보 우위가 가장 큰 주제 |

> 이 주제는 **영어 확장 1순위 후보**다. 한국에서 먼저 나오는 신제품을
> 영어로 먼저 정리하면, 외국 리뷰어가 복제할 수 없는 시차 우위가 생긴다.

## 스킨 — 로즈 + 샴페인

**12개 중 가장 얇고 곱다.** 선이 가늘고 여백이 많다. 굵은 글씨를 거의 안 쓴다.

```yaml
ground:    "#FBF7F7"
surface:   "#FFFFFF"
ink:       "#2A2224"
muted:     "#847479"
accent:    "#B96A76"   # 로즈
accent2:   "#C9A96A"   # 샴페인 골드
line:      "#EFE5E6"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Nanum Myeongjo 400 — **얇은 세리프** |
| 본문 글꼴 | Gothic A1 **300** / 15.5px / 행간 1.9 |
| 모서리 | 10px |
| 이미지 비율 | **1:1** — 제품컷 |
| 배치 | 잡지형, 여백 넓게, 얇은 구분선 |

**이 주제만의 요소:** **성분 배지**(EWG 등급·알레르기 유발·논란 성분)를 제품 글마다.
그리고 **피부타입 필터**(건성·지성·복합·민감)를 상단에.

## 첫 12편

1. 나이아신아마이드 농도별 차이
2. 레티놀 시작 농도와 부작용
3. 자외선차단제 SPF·PA 표기 읽는 법
4. 히알루론산 분자량 차이
5. AHA·BHA·PHA 구분
6. 민감성 피부가 피할 성분
7. 성분표 순서의 의미
8. 앰플·세럼·에센스 차이
9. 여드름 피부 루틴 순서
10. 리들샷·부스터 제품 실제 원리
11. 화장품 유통기한과 개봉 후 사용기한
12. 올리브영 세일 주기와 구매 전략

## 수익 · 주의

- **제휴가 주 수익**(올리브영·쿠팡·아마존). 영어권은 iHerb·Amazon
- ⚠️ **화장품법 표시·광고 규제.** "주름 개선·미백"은 기능성 심사 받은 제품만 쓸 수 있는 표현
- ⚠️ 특정 제품을 "효과 없다"고 단정하면 분쟁 소지 — **성분 사실**만 적는다

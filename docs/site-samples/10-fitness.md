# 10. 홈트·피트니스

> **"제대로 하고 있는 건가."** 자세·프로그램·보충제.

## 판정

| 항목 | 값 |
|---|---|
| 검색량 | **매우 큼** — 1월 급증(신년), 여름 전 급증 |
| 단가 | **상** — 보충제·헬스용품·PT 광고 |
| 스펙트럼 | **최상** — 부위 × 종목 × 수준 × 장비 |
| 진입 | **상(어려움)** — 유튜브가 압도적이다 |
| 영어 확장 | 완벽 — fitness 는 영어권 최대 니치 중 하나 |

## 스킨 — 잉크 블랙 + 라임

**12개 중 가장 강하고 각지다.** 대비를 최대로. 스포츠 브랜드 문법.

```yaml
ground:    "#101112"
surface:   "#191B1D"
ink:       "#F2F4F5"
muted:     "#8B9296"
accent:    "#C6F542"   # 라임 — 에너지
accent2:   "#FF5A3C"   # 경고·고강도 표기
line:      "#26292C"
```

| 요소 | 값 |
|---|---|
| 제목 글꼴 | Gothic A1 **800** — 가장 굵게 |
| 본문 글꼴 | Gothic A1 400 / 16px |
| 숫자 | IBM Plex Mono 600 — **세트·횟수·중량·칼로리** |
| 모서리 | 2px (각지게) |
| 이미지 비율 | 3:4 세로 — 사람 몸이 세로다 |
| 배치 | 카드형, 대비 강하게 |

**이 주제만의 요소:** **루틴 표**(운동·세트·횟수·휴식)를 고정 규격으로. 그대로 따라 하게.
그리고 **난이도 배지**(초급/중급/고급)를 글머리에.

## 첫 12편

1. 스쿼트 무릎 통증 원인
2. 데드리프트 허리 보호 자세
3. 홈트 맨몸 4주 루틴
4. 유산소 언제 하는 게 유리한가
5. 단백질 하루 섭취량 계산
6. 다이어트 정체기 원인
7. 벤치프레스 중량 늘리는 순서
8. 근육통과 부상 구분법
9. 헬스장 첫날 순서
10. 크레아틴 복용법과 오해
11. 계단·러닝 무릎 부담 비교
12. 체지방률 측정 방식별 오차

## 수익 · 주의

- 애드센스(상) + **보충제·용품 제휴**. 01번 영양제와 제휴 라인이 겹친다
- ⚠️ **유튜브가 압도적인 주제다.** 글로 이기려면 **"수치·비교·자세 오류"** 로 좁혀야 한다
- ⚠️ 부상·통증은 의료 영역 — 진단하지 않는다
